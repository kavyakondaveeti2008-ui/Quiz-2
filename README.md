# Quiz Master 🧠✨

A clean, modern, and beginner-friendly General Knowledge Quiz web application built with pure HTML5, CSS3, and vanilla JavaScript.

## 🌟 Features

- **Topic**: General Knowledge (Science, Technology, Geography, History, and Trivia).
- **10 Multiple-Choice Questions**: One question displayed at a time with 4 distinct options.
- **Instant Visual Feedback**:
  - Highlights correct answers in vibrant emerald green (`✓`).
  - Highlights incorrect answers in crimson red (`✗`) while showing the correct answer.
- **Dynamic Progress Bar**: Smooth animated progress tracking completion (`10%` to `100%`).
- **Live & Final Scoring**: Real-time score counter, total score (e.g., `8 / 10`), accuracy percentage (`80%`), and performance badges.
- **Restart Option**: Easily replay the quiz with a single click.
- **Responsive Design**: Clean mobile-first design with rounded buttons, card elevation, and smooth hover effects.
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JS — runs instantly in any modern web browser.

## 🚀 Getting Started

Simply open `index.html` in any web browser:
1. Clone or download the repository.
2. Double-click `index.html` or open it with your favorite browser (Chrome, Edge, Firefox, Safari).

Or run locally with Python:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
